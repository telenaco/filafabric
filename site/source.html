FilaFabric source and licences

The adaptive solid slicer contains the real Arachne engine from Cura and OrcaSlicer, compiled to WebAssembly by Three_Slicer. It is used for flat walls and dense fill; FilaFabric retains its own fabric patterns and printer commands.

The pinned Arachne kernel is licensed under the GNU Affero General Public License, version 3 or later, with upstream copyright notices retained. Its matching sources and the local integration source offer are linked below.

Publication decision pending: FilaFabric’s application-wide publication licence requires the owner’s decision before this Arachne-enabled application is published. This page does not select an application licence. See the source-offer and publication notes.

  • Download FilaFabric integration source — the app's JavaScript, HTML, CSS, profiles, tests and tools; run npm test to verify and npm run serve to serve locally.
  • Download the matching upstream engine build sources — C++, dependency headers, build scripts, licences and provenance for the pinned WASM.
  • Upstream version, attribution and build instructions
  • Integration source manifest and checksums — rebuild with npm run source:snapshot and check currentness with npm run source:verify after reviewing and staging intended new source files.

Other components retain their respective licences, including Three.js and the fonts distributed with the app. Neither this page nor using the kernel publishes any local drawing or print file.
