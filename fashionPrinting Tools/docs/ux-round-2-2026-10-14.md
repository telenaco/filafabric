# UX round 2: one studio for every design

Recorded 2026-10-14. Round 1 (the design canvas linked from `product-direction-2026-10-14.md`) replaced the
49-field form with plain sliders, a verdict and a printer card. Since then a second design (Squiggle & Gyroid)
was added with its own panel, and the studio still did not feel intuitive. This round re-reviewed the running tool
against the brief, the product direction and tools that work the same way, then rebuilt the shell around them.

## What was still in the way

| # | Finding | Effect |
|---|---|---|
| 1 | The second design had its own panel with different controls (select box, plain sliders, no inline errors) | Two tools in one page; nothing learned on one design carried to the other |
| 2 | Undo, share link, save file, reset and reload only knew about the loop pile | Squiggle settings were silently lost; a shared link always opened the loop pile |
| 3 | The first screen was a warning: an amber card at the top of the settings and red tight-spot dots over the model | The model was hard to see and the first impression was "something is wrong" |
| 4 | Three toolbars around a small preview (camera + four layer pills, legend chips, a playback card with two checkboxes, a stats line) | Many controls of equal weight; the preview got the least room |
| 5 | Each slider had a label, an info dot, a boxed number field, a unit, the track and three end labels | Busy, and the boxed "1 ×" for loop size meant nothing |
| 6 | "Link size & density" moved a second slider when the first one moved | Surprising; spacing changed without being touched |
| 7 | The printer card filled half the left column; Export sat in the header, away from the time, filament and check | Deciding to export meant looking in three places |
| 8 | A disabled "Overlapping line (planned)" option sat among the live controls | Noise about something that cannot be used |
| 9 | After Share, the link stayed in the address bar | Reloading later reverted every change made since sharing |
| 10 | Phone layout put the design choice at the very bottom | The first decision was the last thing seen |

## Reference tools and the patterns taken from them

| Tool | Pattern used here |
|---|---|
| Plotcaster (observed in round 1, see `product-direction-2026-10-14.md`) | Style gallery on the left, preview in the centre, the selected style's settings on the right; a few primary sliders, then collapsible groups that summarise their state; a View menu over the preview; one Export |
| MakerWorld Parametric Model Maker (Bambu Lab) | Pick a template, change its parameters with a live preview, download from the bottom of the parameter panel |
| FullControl GCode Designer (design library web app) | Each design is a parametric toolpath with its own parameters; G-code is regenerated from them with no slicer, previewed in three.js |
| Configurators in general (Thingiverse Customizer, Nervous System apps) | Primary action at the end of the settings, next to the numbers that justify it |

Plotcaster and FullControl could not be loaded from the build environment this round, so their rows rest on the
round-1 observation and published descriptions.

## What changed

| Area | Now |
|---|---|
| Structure | Every design uses the same components: Swatch size (width × height with Test / 50 / Full presets), Look and feel sliders, then design-specific groups. A design registry in `main.js` wires both designs to them |
| State | One snapshot holds the design, the loop-pile settings and the squiggle settings (`v: 2`, version 1 links still open). Undo, Share, Save/Open file, Reset and reload work for both designs. A picture used as a pattern stays on the computer; links and files fall back to the centre-spot pattern and say so |
| Header | Printer setup is a compact chip (status dot: amber until the filament is verified) that opens the setup dialog. Undo, redo, Share, and a More menu with Getting started, Save/Open settings file and Reset this design |
| Left | Designs only, as large thumbnails, plus "More designs are on the way" |
| Preview | Opens on the fabric itself: strands at true thickness, at true scale, from a three-quarter angle, framed tighter. Camera presets and a View menu (filament, nozzle path, travel, lifts, exaggerate height, tight spots) sit on the canvas. The legend shows only the parts the current design has. A hint says how to turn and zoom. Playback is one slim row |
| Sliders | Label, one-line help, track, plain end words (Flat ↔ Plush). The value is a read-out you can click to type an exact number (clamped with a note). Loop spacing reads "3 mm apart · 50% overlap", so the size/spacing link is no longer needed |
| Print summary | A footer under the settings: the check (collapsed; amber with an "Add room" button when loops are tight; "Show where" turns on the tight-spot marks), print time, filament, loops or layers, Details, and Export with the file size. Errors turn the check red and say why Export is off |
| Advanced | Each group is collapsible, says how many settings differ from the default, and can be reset on its own; the drawer header says "N changed from the defaults" |
| Squiggle | Structure as two illustrated choices; Pattern as six thumbnails that draw the effect (wavy lines that deepen where the pattern is dark); your picture by drop or browse with "Match its shape"; Two colours as a switch; its own verdict ("Ready to print: two continuous layers with one lift") |
| Phone | Designs as a swipe strip under the header, preview, then the summary, then settings; Export stays pinned at the bottom |
| Help | "Getting started" dialog: the four steps, and the first-print sequence from the README |

Removed: the "Overlapping line (planned)" choice (still planned, see the product direction), the link checkbox,
the info dots, and the separate thickness note (now the View menu's description).

## Still open

- A second loop-pile path ("Overlapping line") once the engine supports it.
- Per-design thumbnails rendered from the engine instead of hand-drawn SVG.
- Printer bundles beyond the MK3S profiles, and the Bambu A1 mini.
- Usability check with someone who has not seen the tool: can they export a test swatch in under two minutes?
